🤖 Активация и Токен бота

Включить Telegram-бота
Токен создается за 1 минуту у официального бота @BotFather командой /newbot.

🔒 Безопасность и Доступ

Защитите вашего бота от посторонних: укажите один или несколько Telegram ID через запятую. Только эти пользователи смогут давать боту команды.

Узнать свой цифровой Telegram ID можно написав боту @userinfobot. Если поле пустое — бот доступен всем.

🌐 Прокси-сервер (SOCKS5 / HTTP для обхода блокировок)

Включить прокси

В РФ прямой доступ к api.telegram.org заблокирован провайдерами. Укажите адрес локального или удаленного SOCKS5 / HTTP прокси (например, v2ray, Xray, Clash, Shadowsocks: 127.0.0.1:2080 или 127.0.0.1:1080).
