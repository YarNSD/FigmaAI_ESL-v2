## [0.11.0-beta.2] — 2026-09-18 (Ветка `beta`)

### 📦 Автоматический установщик для новых ПК (`install.bat`)
- **Умный установщик в 1 клик**:
  - Интерактивный диалог выбора папки назначения (по умолчанию `C:\FigmaAI`).
  - Автоматическая проверка Python в системе (при отсутствии — фоновая загрузка и установка официального Python 3.11 с добавлением в PATH).
  - Проверка наличия **Antigravity IDE** с предложением перейти на официальный сайт загрузки для бесплатной работы ИИ через аккаунт Google без API-ключей.
  - Автоматическое развертывание виртуального окружения `.venv`, установка библиотек и запуск системной верификации.
  - Автоматическое создание ярлыка **«FigmaAI»** на Рабочем столе Windows.
- **Плагин Figma (Zero-Configuration)**:
  - Полный отказ от ненадежной ручной настройки IP-адресов.
  - Плагин настроен на прямое локальное подключение к собственному локальному серверу (`localhost:45678`), гарантируя стабильную работу на любом компьютере.

## [0.11.0-beta.1] — 2026-09-18 (Ветка `beta`)

### ⚡ Производительность и оптимизация токенов (Token Efficiency & Speed)
- **Мультимодальный Vision API (vision_agent.py)**:
  - Внедрена интеллектуальная оптимизация optimize_image_for_vision: перед передачей в Gemini Vision API скриншоты доски и страниц учебников пропорционально масштабируются до 800–1024px JPEG (качество 85).
  - Снижение расхода токенов на Vision-анализ на **60%–70%** (с 6+ блоков тайлинга по 768px до 1–2 блоков на изображение, ~2500 токенов вместо ~12000).
  - **Zero Quality Loss**: Векторные и растровые изображения, вставляемые на холст Figma, сохраняют 100% оригинальное качество и полное разрешение.
- **Целостная генерация урока в 1 LLM-вызов (generate_unified_bloom_lesson)**:
  - Комплексный урок по Блуму (методическая записка, карточки warm-up, словарь, фото-квиз и пропуски) теперь генерируется за **1 единый запрос** вместо 6 последовательных.
  - Расход токенов на сборку урока сокращен с ~10 000 до ~3 300 токенов (**-67%**).
  - Время ожидания генерации сокращено в **3 раза** (~12 секунд вместо ~40 секунд).
  - Улучшена педагогическая согласованность: целевой вокабуляр из таблицы автоматически и сквозным образом отрабатывается в квизе и предложениях с пропусками.
  - Реализован 100% безопасный фолбэк на пошаговую генерацию при сбоях или частичном ответе.
- **Мгновенный Fast-Path для команд (orchestrator.py)**:
  - Короткие прямые команды (до 12 слов с распознанным типом блока и уровнем) обрабатываются моментально по эвристическому маршруту, минуя LLM-диспетчер.
  - Экономия ~450 токенов и ускорение ответа на 3.2 секунды.
- **Компактный системный промпт чат-ассистента (chat_agent.py)**:
  - Промпт сжат с ~950 до ~350 токенов на каждое сообщение (-60%).
  - Полностью сохранены: теплый характер коллеги-педагога, запрет на навязывание планов, обязательное уточнение уровня CEFR, генерация интерактивных чипсов-ответов (suggested_replies) и долговременная память учеников.

## [0.10.0] — 2026-09-18 (Базовый релиз на main)

### 🚀 Первый официальный релиз на GitHub
- **Синхронизация с GitHub (YarNSD/FigmaAI_ESL-v2)**:
  - Чистая публикация кодовой базы, изоляция секретов и токенов ботов (config.json и data/students/ в .gitignore).
  - Создан безопасный шаблон конфигурации config.example.json с автогенерацией при первом старте.
- **Обновления по воздуху (OTA Updater)**:
  - Серверный модуль server/services/updater.py с автоматической проверкой релизов через открытый GitHub API.
  - В Web UI добавлено уведомление о новых релизах, модальное окно с отображением Changelog и 1-клик кнопка [Обновить сейчас] без потери локальных данных.
- **Автоматизация релизов (scripts/release.py)**:
  - Скрипт выпуска версий в 1 команду с предварительной верификацией системы и публикацией GitHub Release.
- **Таксономия Блума (Learning Arc)**:
  - 4-этапная когнитивная траектория (Remember -> Apply -> Evaluate -> Create) для комплексных занятий.
- **Интерактивные механики ESL**:
  - 10-вопросные квизы с 4 рандомизированными вариантами ответов (A, B, C, D).
  - Fill in the Blanks с банком слов и перетаскиваемыми чипами поверх предложений.
  - Двусторонние карточки Peekaboo и Speaking Cards с локальной кнопкой сброса.
  - Автоматическое Оглавление доски (TOC) с категорией «Таймлайн» и кликабельной навигацией.
