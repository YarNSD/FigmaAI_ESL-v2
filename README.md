# ESL Figma AI 🎓

Система агентов-помощников для репетитора по английскому языку.
Создаёт учебные блоки прямо на доске Figma по текстовой команде.

---

## Быстрый старт

### 1. Запустить сервер
```
start.bat
```
Откроется: **http://localhost:3000/ui**

### 2. Подключить плагин Figma
В Figma: `Plugins → Development → Import plugin from manifest...`
Выбрать файл: `figma_plugin/manifest.json`

Запустить плагин на нужной доске.

### 3. Настроить в веб-панели
- Вставить Gemini API Key (вкладка «Настройки»)
- Добавить ссылки на доски Figma

### 4. Создать первый блок
Написать в командной строке:
```
создай квиз A2 на тему кошек
```

---

## Типы блоков

| Тип | Описание |
|-----|---------|
| 🎯 Квиз с картинками | Вопрос + фото + A/B/C |
| 🃏 Открывашки | Карточки с картинкой, раскрываются по клику |
| 🎬 Квиз по видео | YouTube + вопросы по содержанию |
| 📚 Словарь с переводом | Таблица слово/транскрипция/перевод/пример |
| 🗂 Карточки | Простые двусторонние карточки |
| ✏️ Таблица с пропусками | Предложения для заполнения |

## Структура проекта

```
FigmaAI/
├── figma_plugin/     ← Установить в Figma (manifest.json)
├── server/           ← Python FastAPI сервер
│   ├── main.py       ← Точка входа
│   ├── bridge.py     ← WebSocket мост к плагину
│   └── agents/       ← AI агенты
├── web_ui/           ← Панель управления (localhost:3000)
├── .agents/skills/   ← Скиллы агентов
├── config.json       ← Конфигурация (ключи, доски)
├── requirements.txt
└── start.bat         ← Запуск одной кнопкой
```

## Требования

- Python 3.10+
- Figma Desktop (для запуска плагина)
- Gemini API Key (бесплатно на aistudio.google.com)
