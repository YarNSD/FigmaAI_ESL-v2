# 🧠 FigmaAI: Strategic Brain Context

## 1. Миссия и Концепция
FigmaAI — система AI-помощников для преподавателя английского языка (ESL), позволяющая на лету генерировать интерактивные персонализированные учебные материалы и комплексные уроки непосредственно на досках **FigJam** (и Figma Design) во время или перед уроком с учетом возраста ученика (от 8 до 40+ лет) и истории его обучения.

**Формат урока (Screen-Sharing / Single-Operator)**:
- На доске работает **ИСКЛЮЧИТЕЛЬНО преподаватель**. Ученик ничего сам в Figma не нажимает, а только смотрит демонстрацию экрана (Zoom/Meet/Discord).
- Все интерактивные действия (выбор вариантов в квизе, открывание карточек Peekaboo, сброс, навигация по оглавлению) выполняет учитель по ходу устного общения.
- Текст и визуальные элементы оптимизируются под трансляцию экрана: крупные соразмерные шрифты (24-30px), максимальный контраст (чистый черный текст на белом/светлом фоне), плавная навигация через оглавление без хаотичных блужданий по холсту.

## 2. Архитектура Системы
```
[Преподаватель: Диалоговый Чат Плагина / Web UI / Telegram]
           │
           ▼
[FastAPI Server (server/main.py)]
   ├── Conversational Agent (agents/chat_agent.py) -> Педагогическое интервью & память
   ├── Student Memory / CRM (data/students/) -> Профили учеников, статистика, история
   ├── AI Orchestrator (agents/orchestrator.py) -> Google Antigravity CLI (agy)
   └── WebSocket Bridge (server/bridge.py : 45678)
           │
           ▼
[Figma Plugin (figma_plugin/code.js & ui.html)]
           │
           ▼
[Figma / FigJam Canvas: Комплексный урок в одной большой рамке + Методическая записка]
```

## 3. Ключевые Компоненты
- **server/main.py**: FastAPI сервер (REST API для настроек, команд, чата, профилей учеников, bridge на 45678).
- **server/agents/bloom_taxonomy.py**: Педагогический фреймворк Таксономии Блума (6 когнитивных фаз: Remember -> Understand -> Apply -> Analyze -> Evaluate -> Create) для построения целостной методической дуги урока под возраст и уровень ученика.
- **server/agents/chat_agent.py**: Диалоговый агент (напарник-методист). Двухэтапная генерация заданий: подробный текстовый черновик в чате (вопросы, отметка (✅), промпты картинок) для проверки и совместного редактирования, затем перенос точного согласованного контента на холст.
- **server/agents/feedback_agent.py**: Педагогический дебрифинг после занятия. Интерактивное пошаговое интервью (ученик, номер блока 1.1/5.2, вовлечение, языковые пробелы, фокус на след. урок), строго локальная обработка на ПК пользователя.
- **server/agents/student_agent.py**: Долговременная память учеников (`data/students/{id}/profile.json` и `lessons.json`). Собирает фидбеки после уроков (сильные стороны, любимые форматы, зоны роста), отслеживает динамику уровня CEFR, поддерживает правильное склонение имен.
- **server/agents/ai_engine.py**: 100% локальный движок ИИ на устройстве через Google Antigravity CLI (`agy`) и локальную экспертную базу без внешних облачных API-ключей и внешних запросов.
- **server/agents/orchestrator.py**: Оркестрация создания отдельных блоков и комплексного урока («Урок целиком» и «Урок по Блуму»), обязательная верификация присутствия и координат узла на холсте перед рапортом, автокоррекция и перехват предупреждений.
- **server/agents/content_agent.py**: Генератор 7 типов образовательного контента с соблюдением стандартов CEFR.
- **server/agents/image_agent.py**: Двухуровневый поиск и генерация изображений (поиск на Pinterest `site:pinterest.com` / Wikimedia / Google Imagen / Pollinations).
- **server/agents/vision_agent.py**: Мультимодальный агент анализа изображений: OCR учебников с доски и пакетный Vision-анализ пачек фото (до 15 шт) из Figma или Telegram для генерации заданий с оригинальными фото.
- **server/services/updater.py**: Модуль автоматических обновлений по воздуху (OTA Updater): проверка релизов GitHub API (публичный репозиторий YarNSD/FigmaAI_ESL-v2), безопасный `git pull`, pip install и сохранение локальной Student CRM.
- **server/services/backup_service.py**: Резервное копирование и восстановление базы учеников (`data/students/`) в ZIP с манифестом `BACKUP_MANIFEST.json`, защитой от Zip-Slip и форматированием подписи для Telegram.
- **figma_plugin/**: Компактный пульт управления доской (310x160 px): вставка времени занятия, сканирование и скрытие оглавления, окно настроек LAN IP сервера и полное резервное копирование / восстановление доски.
- **web_ui/**: Веб-интерфейс управления с модальным окном обновлений (Changelog Markdown) и бейджем версии.


## 4. Поддерживаемые Типы Блоков (ESL Mechanics)
1. **quiz**: Квиз с вопросом, изображением и вариантами A/B/C.
2. **peekaboo**: Интерактивные карточки-«открывашки» (вопрос/слово, ответ скрыт).
3. **video_quiz**: Квиз по видео с таймкодами и ссылкой на YouTube.
4. **vocab_table**: Таблица словаря (слово, транскрипция, перевод, контекст).
5. **flashcards**: Двусторонние карточки для запоминания слов.
6. **fill_blanks**: Упражнение с пропусками в предложениях.
7. **speaking_cards**: Разминка / карточки для обсуждения.
8. **timestamp_block**: Отметка времени урока (крупное время, полная дата, переход из оглавления).
9. **full_lesson**: Комплексный урок из нескольких блоков в единой общей рамке с методической запиской учителя.

## 5. Главные Инварианты Дизайна (Light Educational Worksheet Theme)
- **Комплексный урок в едином блоке**: Все блоки занятия объединяются внутри общего контейнера (`#f1f5f9`, обводка `#64748b` 3.0px). Шапка урока светлая и выделяющаяся (`#f0f9ff` Ice Blue с рамкой `#2563eb` 3.5px и левой полосой 10px), растянута во всю ширину блока, содержит название, метаданные ученика, состав блоков (`🧩 Состав урока: ...`) и кнопку `📑 В МЕНЮ ↩`. Плашка режима демонстрации экрана удалена. Учебные квадранты имеют четкие 3px границы и индивидуальные цвета (Изумрудный — Разминка, Янтарный — Словарь, Фиолетовый — Квиз). Шпаргалка преподавателя размещается СТРОГО ПОД всеми блоками заданий по всей ширине блока (`2736px`) в 2 аккуратные колонки без лишней высоты и без сырой markdown-разметки. Внизу единая плашка хештегов. Всё объединено в единую группу `figma.group`.
- **Оглавление доски (TOC)**: 10 категорий (включая «🕒 ТАЙМЛАЙН» и «🌟 УРОКИ»). Номера блоков вынесены в отдельные бейджи слева (`[ 1.1 ]`, `[ 9.1 ]`), кнопки компактные в стиле iOS на светлом фоне (`#ffffff`, обводка `#e2e8f0`, шеврон `›`), без сокращений названий. В плагине динамическая кнопка быстрого скрытия/показа оглавления от учеников.
- **Контейнер-фон (Рабочий лист)**: Светлый фон (`#f8fafc` / `#ffffff`) с мягким контуром (`#cbd5e1` 2.5px) и отступами 28-36px.
- **Контрастный текст**: Заголовки 30px bold, вопросы 24px bold, кнопки 20px bold (высота 64px) — цвет чисто черный `#000000`.
- **Инструкции на русском**: С префиксом `👉 ` на полосе `#eff6ff`.
- **Хештеги и Кнопка в меню**: Плашка хештегов `#f1f5f9` внизу и кнопка `📑 В МЕНЮ ↩` со ссылкой на TOC в шапке.
- **Без смещения экрана**: При генерации зум пользователя не сбивается.
